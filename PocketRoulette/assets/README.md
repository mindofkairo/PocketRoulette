# Ledger artwork

`roubles.png` is the owner's supplied EFT currency image, kept unchanged.
The other six PNGs are original geometric icons generated by
`tools/New-LedgerIcons.ps1`; no external icon package or attribution is needed.

Place the PNGs in `assets/` beside `PocketRoulette.dll`. The project and package
script copy them automatically. They are loaded once when opening the ledger,
cached for the raid and destroyed with its UI. Missing images log once per menu
instance and leave the remaining controls usable.
